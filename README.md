# Base On STM32 and Linux Robot
A multi-node heterogeneous embedded robot platform, integrating power management, motion control, machine vision, edge AI, web remote management and secure transmission system.
一套多节点异构嵌入式机器人平台，集成电源管理、运动控制、机器视觉、边缘AI、Web远程管理与安全传输体系

## 📌 Project Overview | 项目概述
本项目为**多板分布式异构机器人控制系统**，由电源管理板、STM32实时控制单元、IMX6ULL Linux主控、树莓派网关多个硬件节点协同组网。
覆盖硬件PCB设计、MCU实时嵌入式开发、Linux驱动开发、多类型电机闭环控制、机器视觉、运动学算法、边缘人工智能、Web前后端开发、加密通信、OTA远程升级等完整工程方向。
学习者可通过本项目一站式掌握嵌入式硬件设计、实时操作系统、Linux底层驱动、各类电机控制算法、视觉AI、服务端开发大量工业实战技能。

## 🔌 Hardware Node Function Description | 硬件节点分工
### 1. 电源管理板
- 供电输入：支持24V DC直流插孔供电 + 太阳能光伏板充电双通路；
- 电源监测：搭载STM32实时采集电压、电流、电量信息；
- 数据交互：通过CAN总线将电源运行状态实时上报至IMX6ULL Linux主控板。

### 2. IMX6ULL Linux 主控板（运动与视觉核心单元）
外接外设：4G通信模块、OV系列摄像头、音频模块、CAN总线、以太网、MPU6050姿态传感器
核心业务逻辑：
1. 通过CAN网络下发指令，实现四轮差速闭环有刷电机底盘运动控制；
2. 向标准六轴机械臂下发目标角度，所有电机运动轨迹采用**S型曲线加减速算法**；
3. 加载并执行机器人运动学脚本，结合摄像头视觉信息完成坐标转换，驱动机械臂实现视觉抓取；
4. 处理姿态传感、音视频采集、跨节点网络数据转发。

### 3. 树莓派（网关节点）
1. 搭载QT图形界面显示屏；
2. 接入IMX摄像头，运行人脸识别本地AI模型；
3. 部署SpringBoot后端服务，实现数据持久化、缓存管理；
4. 后端提供AI推理能力，对上传画面完成物体识别、路况分析；
5. 配套前端可视化页面，实现设备状态监控。

## ⚙️ Core Technology & Algorithm | 核心技术与算法
### 电机控制
- 四轮底盘：差速闭环有刷电机控制
- 执行机构：标准6轴机械臂，S曲线加减速轨迹规划
- 支持步进电机驱动；内置完整FOC无刷电机控制源码

### 嵌入式底层
- MCU：STM32 + FreeRTOS实时操作系统
- Linux：IMX6ULL驱动开发、应用层程序开发
- PCB硬件设计，电源防护电路、低功耗方案

### 通信与安全（重点工程保障机制）
- 组网方式：CAN总线、以太网、4G、WiFi
- 安全机制：非对称性校验、源码加密传输、CRC数据包校验
- 可靠性方案：心跳包机制、日志分级上报、防死机看门狗、硬件故障防护电路
- 远程运维：OTA固件远程升级方案

### 视觉 & AI
- 摄像头图像采集、视觉坐标转换算法
- 本地端人脸识别模型部署
- 云端/后端物体识别、路况分析AI推理

### Web服务
- SpringBoot后端：持久化、缓存、AI推理接口
- 前端可视化监控页面
